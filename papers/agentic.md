# Agentic Image Generation

> A high-precision bibliography of systems that use LLM/VLM agents to plan, call tools, generate, critique, refine, edit, or collaborate on **still-image generation**.

Last checked: **2026-08-29**. Entries are sorted newest first within each section.

## Scope and curation policy

Included in the main list:

- an LLM, MLLM, or VLM acts as a controller, planner, router, critic, memory, searcher, or collaborating agent;
- the agent materially controls still-image synthesis or generative editing at inference time (or learns that policy explicitly);
- systems may be single-agent, multi-agent, tool-using, closed-loop, interactive, or self-improving.

Moved to **Adjacent / enabling work** when the contribution is mainly prompt rewriting, layout extraction, generic multimodal tool use, agent-created training data, or model merging rather than a complete image-generation agent. Excluded: ordinary diffusion/flow models, pure evaluation, safety-only attacks, autonomous-driving/robotics world models, video/3D-only generation, and restoration/enhancement systems unless an agent actually orchestrates generative editing.

Only primary sources are linked: arXiv, official proceedings/OpenReview/PMLR/ACL Anthology pages, official project pages, and author-maintained code repositories. A venue shown as **arXiv preprint** means no accepted venue was stated in the checked primary metadata. Claims made only in an official repository, without a linked proceedings record, are explicitly marked.

### Code legend

- ✅ public implementation or released project artifacts
- 🟡 release announced, incomplete, or official URL not yet exposed
- ⬜ no official public implementation located in the checked primary sources

## Explicit exclusions

- **Pure evaluation** (for example, agentic evaluators that never control generation) is not included.
- **Image restoration / super-resolution / enhancement agents** are not included unless the method orchestrates generative image editing toward a user request.
- **Video, animation, 3D scene, embodied-agent, and autonomous-driving world-model papers** are excluded unless still-image generation is a primary evaluated output.
- **Ordinary unified multimodal generators or diffusion models** are excluded when “reasoning” is only an internal architecture claim and there is no agent policy, tool use, iterative action loop, or explicit multi-agent collaboration.
- **Jailbreak/red-team systems** that use agents only to attack T2I safety filters are excluded from the generation bibliography.
